# Password Generator

## Internship Details
- **Organization:** CodSoft
- **Internship:** Python Programming Internship
- **Task:** Password Generator

## Project Description
The Password Generator is a simple Python application that generates random passwords based on the length entered by the user.

## Features
- Allows the user to specify the password length.
- Generates passwords using uppercase and lowercase letters.
- Includes numbers and special characters.
- Uses Python's `secrets` module for secure random selection.
- Checks for a minimum password length of 4 characters.

## Technologies Used
- Python
- String Library
- Secrets Library

## How to Run the Project
1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   `python password_generator.py`

5. Enter the desired password length.
6. View the generated password.

## Sample Output

    ===== PASSWORD GENERATOR =====
    Enter password length: 12
    Generated Password: [Randomly generated password]
