# Simple Calculator

**Internship:** CodSoft Python Programming Internship

**Task:** Task 1 – Calculator

## Description
This project is a simple calculator developed using Python. It performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero
- Checks invalid operations

## Technology Used
- Python

## How to Run
1. Install Python.
2. Open the terminal in the project folder.
3. Run `python calculator.py`.
